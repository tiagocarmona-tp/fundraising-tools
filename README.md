# Fundraising tools

Small self-contained web tools for nonprofit fundraising planning, published by TwoPurpose.

Each tool is a single HTML file with no external dependencies and no tracking. Default values are generic
placeholders — replace them with your own data before drawing any conclusions.

## Tools

- **[Recurring donor retention business case](recurring-donor-retention/)** — models the 36-month value of
  improving early retention of newly acquired recurring donors: active donors, cumulative revenue,
  acquisition commissions, payback and break-even.

Inputs can be pre-filled through the query string, e.g.
`recurring-donor-retention/?donors=10&gift=10&cac=100`.
